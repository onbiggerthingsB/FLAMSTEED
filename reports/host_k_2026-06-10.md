## 2. The estimate (k_elo MLE ± bootstrap CI)

- **k_elo = 1.422** (95% CI [1.178, 1.642], 2000-resample seeded match-bootstrap, seed 20260611).
- MLE of the host home advantage as a multiple of standard home advantage (Elo unit = 100, draw_base = 0.28). k_elo = 1.0 ≡ hosts behave like an ordinary home team; k_elo = 0.0 ≡ neutral; the host overperformance is k_elo − 1.0 = **0.422** standard-home-advantage units.

### Unit mapping into the model's `host_k`

`host_k` multiplies the fitted home advantage for a 2026 host's in-country game; it is *exactly* "host advantage as a multiple of standard home advantage" — the SAME quantity `k_elo` estimates. The mapping is therefore the **identity** (no rescaling):

> **host_k_model = k_elo = 1.422** (round to **1.4** for adoption).

**Net-edge both ways** (spec §1, pitfall 2):

- (a) As a multiple of standard home advantage: the host carries `k_elo · home_adv` (k_elo = 1.422), vs an ordinary home team's `1.0 · home_adv`.
- (b) In the 2026 sim: a host group game uses `(host_k·ha, 0)` while every other group game is neutral `(0.5·ha, 0.5·ha)`. So the host's NET edge over a neutral opponent on the home side is `(host_k − 0.5)·ha` = **(1.422 − 0.5)·ha = 0.922·ha**, versus the current `(0.5 − 0.5)·ha = 0` net edge at host_k = 0.5.
